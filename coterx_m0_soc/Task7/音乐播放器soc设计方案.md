## 内部子模块接口

### 键盘扫描模块 - Keyboard

**功能**：完整的键盘接口管理，包括扫描、消抖、中断生成

| 端口名称 | 方向 | 宽度 | 功能描述 |
|---------|------|------|--------|
| `clk` | input | 1 | 系统时钟 |
| `rstn` | input | 1 | 复位信号（低有效） |
| `key_clear` | input | 1 | key_reg清除脉冲 |
| `col[3:0]` | input | 4 | 列扫描输入 |
| `row[3:0]` | output | 4 | 行驱动输出 |
| `key_interrupt` | output | 1 | 键盘中断信号 |
| `key_reg[15:0]` | output | 16 | 键盘状态：1：键盘被按下  0：键盘没有被按下 |

存储多首歌曲时，每一首歌有一块单独的ROM吗？
是的；

音调和节拍按照什么格式存储在ROM中？
一共12bit，{音调高4bit,音调低4bit，节拍4bit};

节拍与节拍之间的切换会从频率A突然切换到频率B，这个切换过程是否需要做特殊处理？ 没有特殊处理
